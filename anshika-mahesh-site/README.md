# Anshika Mahesh — Story Site

Public site for young author **Anshika Mahesh**. Source: [rkmaheshglobal/anshu-stories](https://github.com/rkmaheshglobal/anshu-stories).

This repository is the live website only — HTML, CSS, JavaScript, and story art. Notebooks, scans, and working drafts stay off GitHub.

## Pages

- `index.html` — Home / brand
- `about.html` — About Anshika
- `stories.html` — Story library
- `newsletter.html` — Subscribe (Story Notes)
- `connect.html` — Contact links

## Preview locally

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Go live

GitHub Pages from this repo (Settings → Pages → Deploy from branch `main` / root), or drag this folder onto **Netlify** / **Vercel**. Point a domain such as `anshikamahesh.com` at the host when ready.

1. Replace `hello@anshikamahesh.com` on Connect with your real parent email.
2. Hook the newsletter form to a real list (Buttondown, Mailchimp, or ConvertKit) when ready — the form currently shows a local thank-you message only.

## Safety defaults

- Parent-managed contact
- No public comments
- Newsletter copy notes unsubscribe + parent-managed list
