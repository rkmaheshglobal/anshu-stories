# Anshika Mahesh — Story Site

Public site for young author **Anshika Mahesh**. Full clone, run, and publish steps are in the [repository README](../README.md).

This folder is the live website — HTML, CSS, JavaScript, and story art.

## Run from this folder

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080). Do not start the server in the parent folder, or story links will 404.
